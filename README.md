# EPL 축구 유니폼 재고 관리 시스템

### 1. 인기 구단 선정
* EPL 주요 6개 구단
  * 맨체스터 시티 (MCI)
  * 맨체스터 유나이티드 (MUN)
  * 첼시 (CHE)
  * 아스날 (ARS)
  * 애스턴 빌라 (AVL)
  * 리버풀 (LIV)

### 2. 유니폼 관리
* **일련번호** : `00000` (5자리 고유 코드)
  * 앞 2자리: 팀 코드 (10 ~ 60)
  * 중간 2자리: 선수 등번호 (01 ~ 99)
  * 맨 뒤 1자리: 유니폼 종류 (0 : HOME, 1 : AWAY)
* **상품명** : 선수 이름 + (팀 약어)
* **사이즈** : FREE
* **가격** : 미정
* **재고** : 00

### 3. 테이블 구성
| 일련번호 | 등번호 | 선수명(팀) | HOME or AWAY | 재고 수량 | 가격 |
| :---: | :---: | :---: | :---: | :---: | :---: |

## 주요 기능

### 1. 로그인 / 권한 제어
* **게스트 (Guest)** : 기본 접속 모드 (재고 조회 및 검색만 가능)
* **관리자 (Admin)** : 아이디/비밀번호 입력 후 로그인 (재고 추가, 수정, 삭제 등 전체 기능 사용 가능)

### 2. 팀 선택 메인 화면
* 로그인 후 EPL 6개 구단 목록 화면 출력
* 원하는 팀 선택 시 해당 팀의 세부 재고 현황으로 이동

### 3. 팀별 유니폼 재고 관리 화면
* **재고 현황 조회** : 선택한 팀에 속한 선수들의 유니폼 재고 목록 출력
* **검색 기능** : 등번호 또는 선수 이름을 입력하여 실시간/필터링 검색
* **재고 추가** : 팀, 등번호, 선수명, 유니폼 종류, 재고 수량, 가격 입력 시 일련번호 자동 생성 후 DB에 추가
* **재고 변경** : 목록에서 변경할 항목 클릭 후 수량 수정
* **재고 삭제** : 목록에서 삭제할 항목 클릭 후 DB에서 삭제
* **뒤로가기** : `[팀 선택으로 돌아가기]` 버튼 클릭 시 팀 선택 메인 화면으로 복귀
